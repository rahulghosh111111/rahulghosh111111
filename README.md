### 🌟 Flagship project: Ira Assistant

**[Ira Assistant](https://github.com/rahulghosh111111/Personal-Assistant-releases)** · *private, invite-only* · Python · PySide6 · Whisper · Ollama · ONNX

A local-first, voice-locked desktop assistant for Windows. It wakes only to its owner's voice, understands **English, Hindi, Bengali, Hinglish and Banglish**, and controls apps, the browser, files and the screen, with **no cloud AI and no API keys**.

- 🎙️ Offline wake word, voice-activity detection, barge-in, and Whisper speech-to-text fine-tuned for Hindi and Bengali
- 🔐 Voiceprint lock, risk-rated actions behind a single safety gate, an undo journal and an encrypted audit log
- 🧠 Rules first, with a small local LLM (Ollama) only as a fallback planner; OCR and local vision to read and click anything on screen
- 📦 Qt desktop app with tray, setup wizard and signed, self-verifying updates, backed by **1,900+ automated tests**
