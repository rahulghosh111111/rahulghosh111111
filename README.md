## 🌌 Featured Project

<h3 align="center">🚀 IRA ASSISTANT</h3>

<p align="center">
  <img src="https://img.shields.io/badge/PROJECT-PRIVATE%20%7C%20INVITE%20ONLY-7C3AED?style=for-the-badge" />
  <img src="https://img.shields.io/badge/PLATFORM-WINDOWS-06B6D4?style=for-the-badge" />
  <img src="https://img.shields.io/badge/TESTS-1900%2B-16A34A?style=for-the-badge" />
</p>

**A Local-First, Voice-Locked Desktop Assistant**

A powerful Windows desktop assistant designed to understand natural speech, recognize its owner's voice and automate computer operations without depending on cloud AI services or API keys.

**Core capabilities:**

- 🎙️ Offline wake-word detection and speech recognition.
- 🌍 English, Hindi, Bengali, Hinglish and Banglish support.
- 🔐 Voiceprint authentication and risk-based action protection.
- 🧠 Local intelligence using Ollama as a fallback planner.
- 👁️ Screen understanding using OCR and local vision.
- 🖥️ Windows application and browser automation.
- ↩️ Undo journal and encrypted audit logging.
- 📦 Desktop interface with setup wizard and self-verifying updates.
- 🧪 1,900+ automated tests.

**Technology:** Python · PySide6 · Whisper · Ollama · ONNX Runtime
